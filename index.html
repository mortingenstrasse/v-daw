Recording, calibration & platform notes

Use headphones and interface direct monitoring. Start engine, then choose audio input/camera in Studio settings. Record begins after two bars of count-in. Cycle recording wraps and replaces the previous pass in the recorded interval; Undo restores it and the original continuous take can be downloaded. Export uses the full timeline. Input monitor has browser latency; use headphones, or turn it off for interface direct monitoring. Camera/audio require HTTPS or localhost. Session media is held in memory; download takes before leaving.

Loopback measures round-trip audio latency, not camera or isolated input delay. It cannot remove live monitoring latency. iOS Chrome must be tested on the actual device: USB routing, recording and canvas export depend on its browser/OS. MP4 export requires native H.264 + AAC recording support; unsupported browsers display an explanation instead of a renamed WebM.

Open without browser bars

On iPhone, open the browser’s Share menu → Add to Home Screen → Open as Web App (if offered). Then launch v-daw from its Home Screen icon. On some versions this option is available in Safari.

Download your current takes first: sessions are memory-only and do not transfer to the Home Screen app. Full screen and Home Screen mode do not enable background recording.

Studio settings

Start engine to reveal available devices. Change the OS output route before calibration.

Physical loopback calibration

  1. Stop recording. Turn interface direct monitoring off to avoid feedback.
  2. Connect a low-level line/headphone output to a compatible line input. Start with low output volume; do not connect to a phantom-powered mic input.
  3. Select that input above and reconnect. Set the OS output to that interface. Disconnect speakers.
  4. Run the three-pulse measurement. Then remove the loopback cable, restore your recording input and direct monitoring.
